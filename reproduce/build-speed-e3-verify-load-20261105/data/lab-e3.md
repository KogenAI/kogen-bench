QUESTION. Are the 10 host_or_base_failure Builds (each ~20-28 min in verifying = two 600 s go test timeouts) and the 28 land-red retries load-induced, flaky or real?

ARMS. A: re-run the failing check solo on a quiet EU. B: re-run it under E2's replayed 4-Build load (the E2 arm-B schedule, looped for the whole run, so 4 suite streams are always in flight). 3 reps per arm per check, interleaved A,B.
ITEMS (20): the 10 host_or_base Builds (verification x3, shaping x6, loop x1) and 10 of the 28 land-red retries, selected before running as the first 10 land-red rows (chronological, auto-retried.tsv, window 3 Nov 09Z to 5 Nov 09Z) that name a failing test in kogen-build.
CHECK. The failing check, scoped to the failing test or package where the log names it: verification = go test -run TestProbeCustodyAndResults ./verify ./contract (the test every verification timeout names); loop = go test ./sys; land-red = go test -run <named test> ./... in kogen-build. Shaping (6 Builds, test not named in the retained evidence; eu2 logs are off-limits while cc-layers-1 holds eu2) = the full kogen-shaping go test ./... (heavy, so a reduced rep count is allowed and recorded).
TREES. The original candidate and land trees were deleted by janitors (src dirs gone on all hosts). Proxy tree = the repo's main at the nearest commit we can name (recorded per item). A check that passes everywhere on a proxy tree is "not reproduced", not "load-induced".
METRIC. Pass/fail (rc) and duration per run. Class per item: load-induced = passes in all A reps and fails in at least one B rep; flaky = mixed results within one arm; real = fails in every A rep; not-reproduced = passes in all A and all B reps. Duration also reported (B/A ratio).
DECISION RULES. The fix is chosen per bucket (host_or_base, land-red) by the dominant class: load-induced (>= half of the bucket's items) -> a scheduling or timeout fix request; flaky (>= half) -> one rerun before requeue for land-red; real or not-reproduced (>= half) -> no load fix, no request for that bucket; ties go to the class with the larger time cost. The report's rule "nothing if real" stands. Evidence quality caveat is stated in the verdict whenever the dominant class is not-reproduced.
