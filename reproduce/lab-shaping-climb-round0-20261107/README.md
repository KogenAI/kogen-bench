# Shaping readiness on a fixed request set

A shape-only baseline reached a ready Intent without a question on 9 of 21 requests: 9 of 15 small requests and 0 of 6 complex requests. This is a baseline, not evidence of an improvement. Eight results ended as not ready, two as invalid output, and two with questions. The complex request text is private; the data preserves outcomes without it.

The run used Sol at low effort with no answerer and the release built from [Kogen source](https://github.com/KogenAI/kogen/commit/47236bbb93385bc960fd2ac353c9b000bd6ed571). Each request was run once. A result is ready only when it reached readiness with no questions or refusals. No Build or hidden evaluation was run. Small Go and Node workspaces were reconstructed from the earlier study description; byte identity with the original workspaces is unverified. Account-wide credit readings did not move visibly, but do not establish attributable spend. The cell data records elapsed time, including failed attempts.
