# Review refusals have distinct causes

Two observed invalid reviews at Kogen 2e6a8976bab3838b7db1ac4dbd9e0c51d99f1ed0 (review pin [cdcbbe3e](https://github.com/KogenAI/kogen-review/tree/cdcbbe3e357a67127700ddaa190b672fa5241c4f)) had different causes: one of two involved extra escaped quotation marks, and one of two was correctly held on unread evidence. These are two selected failures, not an estimate of the population rate.

Onboarding Build 53563458 submitted two structured changes verdicts with blockers. The first paraphrased an unmet requirement. The retry quoted it but included literal backslashes before inner quotation marks. The [requirement gate](https://github.com/KogenAI/kogen-review/blob/cdcbbe3e357a67127700ddaa190b672fa5241c4f/review/independent.go#L1215) requires a blocking message to contain the exact requirement after whitespace and case normalization. The saved retry passed through the actual Go requirements validator in a model-free replay: baseline reported one problem, scratch quote normalization reported zero. That is a replay of this gate, not of all verdict checks or a claim the candidate was correct. A scratch change that normalizes backslash-escaped double quotes for the quotation comparison is plausible; it does not repair the first paraphrase or approve the Build. The existing targeted IndependentReview and ExternalReview Go tests passed on the scratch change. No negative tests for other escape patterns were run; the change is not qualified for delivery.

Documentation Build c60fc93e attempted changes without a blocker with 212 pinned parts unread, then approval with 182 unread. The [unread gate](https://github.com/KogenAI/kogen-review/blob/cdcbbe3e357a67127700ddaa190b672fa5241c4f/review/independent.go#L1025) correctly refused incomplete review. This calls for reviewer completion, not a weaker gate. Build a1e351e3 had a valid blocker concerning unverified run-log preservation; the blocker's substantive correctness is unverified. Build bb178205 had a valid blocker describing a Darwin regression probe where a detached child survived termination; the probe has not been independently repeated. Valid changes verdicts map to review_blocked at [independent.go](https://github.com/KogenAI/kogen-review/blob/cdcbbe3e357a67127700ddaa190b672fa5241c4f/review/independent.go#L523). No model cells were run.

Earlier work [RC-B](../lab-rc-b-review-listed-requirements-20261106/README.md) addresses a separate binding rule for requirements from refused submissions. The quote normalization here does not claim to fix that rule.
