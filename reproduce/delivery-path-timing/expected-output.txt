## 2. Task -> trigger index

Trigger definitions: red_start = a `before_change` command (baseline/setup check) exits non-zero; long_shell_300 = a logged command (command->command_result) >300 s; review_repair = a review verdict event with non-empty findings; deadline = outcome `timeout`; no_submit_refusal = outcome refused/invalid_response/questions_pending/no_progress/review_invalid, shaping submission_refused, or builder_blocker; large_review_150 = review_source/material parts >=100 (NO log has >150; max observed 119, so strictly 0 cells); repeat_verif = same non-baseline verification command re-run with no write_file AND no builder shell call in between (strict lower bound; looser definition ignoring shell calls gives the `repeat_loose` count in 2d); provider_stall = a request with wall >=180 s, or >=2 provider attempts beyond requests.
