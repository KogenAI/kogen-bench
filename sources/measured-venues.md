# Public venue identifiers

These identifiers support benchmark record grouping. Host hardware, CPU counts, memory, disk capacity, operating-system versions, and kernel details are withheld from the public record.

| Identifier | Type | Role |
| --- | --- | --- |
| kogen-bench-us | Execution venue | US benchmark host |
| kogen-bench-eu | Execution venue | EU benchmark host |
| studio | Execution venue | Studio venue identifier |
| orchestrator-control | Grading infrastructure | Official grading pipeline identifier; not an execution venue |
