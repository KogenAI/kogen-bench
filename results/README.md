# Per-cell outcomes

See the [public glossary](../rounds/GLOSSARY.md) for model and analysis terms. [cells.csv](cells.csv) and [cells.jsonl](cells.jsonl) are equivalent sanitized tables generated from the official grade snapshot and the supplemental FE2 rerun receipts identified below. [export-report.json](export-report.json) gives coverage and duplicate-reconciliation counts; [unmapped.json](unmapped.json) lists missing round/model/usage fields and unresolved inclusion cases.

These are outcome observations, not replacements for per-round planned denominators. Ungraded failures are absent, historical corrective cohorts remain separate, and smoke/control rows have intention-to-treat (ITT) outcome `not_scored`. Cost estimates are source-reported API equivalents; their calculator and analysis inputs are not in this snapshot, so the calculations are not re-derivable from the public record. Inspect [METHOD.md](../METHOD.md) before pooling results.

Refreshed export coverage: 5,064 official cell rows; 50 unassigned round tags; 167 unresolved ITT causes; 2,481 rows have at least one missing or unmapped field or unresolved cause.

The [run-record index](run-records/index.json) lists separately fingerprinted Standard 1.2 JSONL files for each tagged round and `unassigned.jsonl` for the 500 records with no unambiguous owning round tag. Each entry records the round ID, record count, byte length, SHA-256, and schema version. Compact missing codes are expanded by the [missing-reasons legend](missing-reasons.json). These records describe observed captured deliveries and task IDs; they are not a statement of a round's planned task list. See [STANDARD.md](../STANDARD.md), [capture provenance](../reproduce/inputs/run-evidence-provenance.json), and the [per-round validation summary](validation-summary.md). The output is distinct from the older `cells.*` outcome export and includes 1,501 surviving ungraded deliveries; it still cannot establish every planned delivery or prove that no deleted delivery existed.

The [source-crosswalk index](source-crosswalk/index.json) lists per-round row-level source identity and outcome-linkage files. The run, context, and ungraded source evidence are likewise split by round under `reproduce/inputs/` and have one index per family. The capture ledger has 5,020 unique graded delivery IDs. The refreshed public `grades.final.jsonl` export exact-joins all 5,020 IDs; 128 official post-cut rows were appended on 2026-10-07. Of those rows, 84 are model passes, 19 are model failures, and 25 are invalid control applications that are not model failures. See the [grade ID and publication scope report](GRADE-JOIN.md) and the [publication validation report](publication-validation.md).

## Supplemental Round 70 receipts

[test-counts.jsonl](test-counts.jsonl) publishes 88 latest official hidden-test count rows: 40 original RvE cells, 15 FE2 rerun cells, 29 extension cells, and four task-8 smoke rows. Each row includes runner status, exact cell ID, hidden tests passed/total, and grade timestamps. The four task-8 smoke rows are marked `scored: false`.

[controls.jsonl](controls.jsonl) publishes 122 admission and X-control rows for the rerun, extension, and task-8 cohorts. Every control row is marked `scored: false`. `window_time` is the official grade-window start. Controls come from operator grade windows whose window captures are internal and not published. `window_snapshot_at` is the time recorded for that grade window, at or after `window_time`. `window_id` is `<host>@<window_snapshot_at>`, a host and time label only. Earlier invalidated grade rows are excluded. Where an exact cell ID has a later official grade, only that latest row is included.

Patch hashes are recorded only when present in the authorized public receipts. `no_patch` identifies a no-op control; `not_published` means the permitted receipt did not provide a patch hash. Failure causes are broad classes only. The ledgers contain no hidden-test names, grader material, local paths, or usernames.

[cost-time.jsonl](cost-time.jsonl) has one row per exact `cell_id` for 20 original RvE Rust/Elixir cells, 15 FE2 rerun cells, and 29 extension cells. The 20 original RvE rows have source-reported API-equivalent cost, version hashes, reasoning and other token counters, requested/effective model and effort, and recorded Codex CLI/harness version data. Cache-write token counts are unavailable for these 20 rows and remain null. Reasoning is a subset of output and is not counted twice. For the remaining 44 rows, cost, reasoning, cache-write counts, effective model/effort receipts, and verified harness versions are unavailable and are null, not zero. The [cost-time metadata](cost-time-metadata.json) gives the calculator, price-table versions, and caveat. Cost is not invoice spend. `wall_s` is agent run wall seconds; join each `cell_id` to [test-counts.jsonl](test-counts.jsonl) for official outcome and host. Wall values are comparable only within a host.
