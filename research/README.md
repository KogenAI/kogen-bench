# Research index

**Scope:** this file transfers the R3 study-directory census and names the unresolved source/run dispositions. It is a metadata register, not a set of study results.

The census contains all entries listed in the R3 research inventory. Its index-status column is the snapshot recorded there as of 6 October 2026; the research cut is 7 October 2026. R3’s later decision addendum takes precedence where it conflicts with the earlier registry, but this index does not claim a study-by-study source review.

**Source aliases:** `C/<slug>/README.md` is the migration-source alias from the publication plan, not a public URL or local filesystem path. The R3 inventory reports a README for each listed study except `kogen-language-choice`; this pass did not inspect source READMEs or check their current filesystem availability. Study-specific dates were not given in the permitted census and remain unverified.

**Decision references:** R1–R4 do not assign a stable public product `decision_id` to each study. The H IDs below are topic-navigation associations derived from the R1/MASTER-MAP hypothesis register only; they do not say that a study tested, supported, or decided that hypothesis. Claim IDs remain unassigned until exact-cell reconciliation is available.

**Publication gate:** no per-study synthesis is added here. The R3 numeric excerpts remain **source-reported, not reproducible from public data** until each claim is joined to a permitted public receipt and its analysis is reproduced. A linked round page is a related receipt pointer, not proof that it is the source for the study. No numeric result from a private study README is copied into this index.
