# Grok frontier design record

Terminology: [public round glossary](../GLOSSARY.md).

## Status

**NOT-RUN.** The study was aborted before a smoke or scored cell ran. The planned smoke and all 14 planned cells are cancelled; there are no active release instructions or results to analyze.

## Planned question and scope

The proposed descriptive question was how Grok Build performed on seven public tasks relative to selected official reference cohorts. The public [aggregate plan](PLAN.json) listed two repetitions per task, or 14 planned cells. Host-specific plan files and the proposed reference-outcome report are not included in this repository, so exact host allocation and comparison-row membership are not re-derivable from the public record.

## Evidence and limits

The public results export contains no Grok frontier rows. The plan does not support any task result, pass-rate comparison, significance test, superiority claim, or non-inferiority claim. The withdrawn r74 design is not a completed reference cohort. No result is inferred from quota, account, hardware, operating-system, or machine-capacity information.
