# ARCH-20261011 deviations and audit record

The frozen comparison asked whether Elixir core plus a Go command-line interface (CLI) materially improves fault robustness over a Go-only core under a 90-minute build and 30-minute maintenance budget. A result requires at least three complete preassigned same-host pairs; otherwise the frozen decision rule returns INCONCLUSIVE. With enough pairs, Elixir wins only if its median F advantage is at least three and its median total tokens are no more than 1.5 times Go's; otherwise Go wins. F is build-final fault tests passed; B is baseline behavior and M is maintenance behavior. Four pairs were preassigned and not rematched.

Three attempts are recorded. D-1 was interrupted by a Studio reboot. D-2 was harness-invalid after a hardlink stopped snapshot capture and a changed arm-kit file invalidated the first wave; the second wave did not start. The harness was fixed to capture hardlinked files safely, isolate capture failures per arm, and accept the reference scorer’s report format. A dry cell using reference scoring passed before Relaunch 2. D-4 was a G3 maintenance start-watchdog infrastructure failure: the watchdog killed the stalled process before its first event, so this was not an agent result. D-5 records the post-run audit correction: 24 flagged candidates were reviewed; three implementation rounds were independently reviewed and each sent back for revision. No flag could be removed to the review standard, so validity did not change.

Under the ORIGINAL audit, E2 alone was valid; its preassigned partner G2 was invalid, leaving zero complete pairs. Under the post-run audit correction D-5, validity is unchanged and there are still zero complete pairs. The ruling is INCONCLUSIVE under both readings. The previously recorded direction, Elixir core plus Go CLI, stands. No outcome is inferred from descriptive scores.

The audit inferred reads from command text, which misclassified inert path text. The designed fix is to deny reads outside allowed roots at the source and record operating-system file-access evidence. This design has not yet been validated on a real dry cell. The audit remains limited by its static analysis and recorded evidence.
