# Race 4 results

`cells.tsv` contains the 20 counted host/wave/language FINAL rows.

In cells.tsv, ts means TypeScript/Bun and ex means Elixir. FINAL/88 is the passing-case count at the final checkpoint. reached_target records reported target attainment. build_test_seconds covers recorded build/test command spans, not total elapsed time. audit_flags counts flagged commands requiring review, not confirmed violations. n/a means unavailable. `FINAL.tsv` and `FINAL.md` show cell scores; `curves.tsv` and the remaining tables contain aggregate snapshots, timing, resource, audit and token summaries.

Per-case files, score JSON, and ID/status/timing projections are withheld while the experiments using the same cases (L1–L3) run because they contain suite step data or test content; Release is planned after the experiments using these cases (L1–L3) finish; the announced estimate was about 15:00 East Africa Time on 11 October 2026, not a confirmed time. Raw host logs are not part of this publication. The race README and `MISSING.md` describe the withheld material.
