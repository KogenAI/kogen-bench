# Frozen v4 decision rule

Apply separately to each endpoint's one frozen plan and one live execution. Process pairs in scheduled order. A request is transport-complete when dispatched, HTTP 200, and final provider input, cached-input, and output counters are present and internally valid (`input > 0`, `0 ≤ cached ≤ input`, `output ≥ 0`). Terminal stream status `incomplete` is recorded but does not change this counter-based classification. A pair is transport-complete only when both primers and both probes meet this rule. Eligibility never examines the size of `cached` except for counter integrity.

Record every transport-incomplete pair and its reason. Replace it with the next already frozen fresh pair; never reuse a session or rerun an episode. Stop at 11 complete pairs or after 15 attempted pairs. Stop cleanly before a dispatch that would exceed 60 POSTs or 700,000 charged/reserved tokens, and during streaming if the hard budget guard fires. Failure to reach 11 complete pairs, cap hit, authentication failure, model mismatch, plan or integrity failure, or protocol deviation makes STATUS **INVALID**. Otherwise STATUS **VALID**, independently of the cache outcome. A zero-cache measured probe is complete and stays in the 11-pair denominator.

For each complete pair, calculate `S = shared cached/input` and `D = distinct cached/input`. H-BACKEND pair success is `S ≥ 0.80 AND D ≤ 0.05`. H-API pair success is `D ≥ 0.80`. Let K be successful pairs among the first 11 complete pairs. The primary one-sided exact p value is `sum(j=K..11) C(11,j)/2^11`; this tests the preregistered 0.5 benchmark for pair success. The directional finding is SUPPORTED only if STATUS VALID and `K ≥ 10` (p ≤ 0.01); otherwise it is NOT SUPPORTED if valid, or UNDETERMINED if invalid. Report K/11, p, and the two-sided 99% Clopper–Pearson interval for the pair-success frequency. The interval is not a future cache guarantee.

For H-API, also report every paired `D-S` share difference and an exact two-sided sign p value on nonzero differences, with ties omitted from that secondary test. This comparison does not change STATUS or the primary finding. Report cached/input totals for all measured probes in each arm, complete-pair totals separately if they differ, observed share ranges, number/reasons of replaced pairs, POST count, charged/reserved tokens, output-limit terminal counts, model, prefix length, and actual primer-to-probe gaps. No prior-round observation is pooled into v4.
