# Tenant access diagnosis

Written before changing the application or tests.

## Violated property

The fixed `read_iff` law and `contract.md` require `TenantGate.can_read/2`
to return true exactly when all three required fields are present, the tenant
tokens match, and the role is `owner` or `viewer`. A viewer must therefore be
denied access to another tenant's resource.

## Evidence and cause

Baseline `./fv check` (cycle 1) regenerated the current application with hash
`3c65080bc3fc74121f65c6b5d09756aca2d25dfb39904aa115180d70f6472108`
and failed `read_iff` at bound 0 with this counterexample:

```elixir
actor = %{tenant: :t2, role: :viewer}
resource = %{tenant: :t1}
TenantGate.can_read(actor, resource) # actual: true; required: false
```

The source trace includes `can_read/2`, `fields_present/3`, `role_admitted/3`,
`owner_read/3`, and `viewer_read/3`. For these inputs, all required fields are
present. `owner_read/3` returns false, but the causal function `viewer_read/3`
at `app/lib/access.ex:41` discards both tenant arguments and checks only
`role == :viewer`. Consequently `role_admitted/3` returns true, which passes
through `can_read/2`. The regenerated Quint definition also contains only
the viewer role comparison, confirming that the missing tenant check is in
the application itself.

The starter test passed because it exercises a same-tenant viewer, a
same-tenant owner, a guest, and a missing actor tenant, but no cross-tenant
viewer. This is a witnessed implementation defect, not a proof or tooling
limitation.

## Intended repair and verification

Require tenant equality in `viewer_read/3`, preserving every public function
name and arity and the existing missing-field guard. Add a native regression
test for viewer denial in both cross-tenant directions. Leave the accepted
contract, laws, domains, and assumptions unchanged. Run `./fv check` again
to regenerate the IR, Quint implementation, and source map from the repaired
Elixir source and check the fixed law and ExUnit tests.

## Checker constraints encountered
