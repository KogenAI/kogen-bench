# Tenant access diagnosis

## Violated property

The fixed `read_iff` law requires `TenantGate.can_read/2` to return true
exactly when all required fields are present, the tenants match, and the
actor's role is `owner` or `viewer`. Cross-tenant viewer access violates
the tenant equality requirement.

## Evidence before repair

The first `./fv check` regenerated the implementation from the original
application (hash `0af3e31548af749a1f6c852c1ad6834acc9ae1a1b869f74194e7ea6e7f460a88`).
It reported `FV-LAW read_iff FAIL`, `FV-LAWS 0/1`, and exit code 1.
Lean reported that `decide` proved `check_read_iff = true` is false.
The supplied starter test passed. The checker did not print a concrete
`FV-COUNTEREXAMPLE` line, but it traced the law through the application,
including `lib/access.ex:41-42`.

A concrete witness follows directly from those source expressions:
`actor = %{tenant: :t1, role: :viewer}` and
`resource = %{tenant: :t2}`. All fields are present, so `fields_present/3`
returns true. `owner_read/3` returns false, but `viewer_read/3` returns true
solely because the role is `:viewer`. Thus `role_admitted/3` and then
`can_read/2` return true, although the contract expects false. Both inputs
belong to the accepted finite domain. Reversing the two tenants has the
same defect.

## Causal function and repair

`viewer_read/3` in `app/lib/access.ex:41-42` names its tenant arguments
`_actor_tenant` and `_resource_tenant` and never compares them. Its role-only
predicate causes the violation; the owner predicate and required-field
guard already enforce their respective conditions.

Change `viewer_read/3` to require `role == :viewer` and
`actor_tenant == resource_tenant`, preserving every public function name
and arity. Keep the contract, fixed laws, domains, and assumptions unchanged.
Run `./fv check` to regenerate IR, Lean implementation, and source map from
the repaired application and verify the fixed law and starter tests.

## Failure classification

The initial failure is an implementation defect: the source witness violates
the contract and Lean computes the law to be false. It is not an unresolved
proof or a tooling limitation. A separate attempt to execute Elixir directly
could not run because `elixir` is unavailable on the interactive shell's
PATH; the supplied broker successfully compiled and ran the starter test.
