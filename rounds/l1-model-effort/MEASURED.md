Measurements — L1 model and effort pilot

The public scores and aggregate token counts are summarized in
[README.md](README.md) and [results.json](results.json). Eight Standard
records cover four planned conditions in each language. Seven slots
started; six ran to their cap and one was interrupted after 98 seconds.
The remaining US condition was not run.

This is a descriptive pilot with one run per condition per language.
The host and language vary together, so results are compared only within
each language. The disclosed retirement, interruption and offline
scoring limit interpretation.
