# Measurements — Kogen-RS R74 tier-1

## What is measured

The published `RESULTS.md` tables report the 18 planned cell outcomes, per-cell wall time, request counts, token counters, and aggregates. They also report three invalid XDG-1 attempts and the DEV-1 timing note. These values and their extraction are source-reported; they are not independently reproducible from the public snapshot. The recovered R74 Codex rows linked in the round README provide historical context and are not joined to the canonical official export.

## What is not established

The public snapshot contains no Standard 1.2 run record for the 18 cell IDs. It contains no public smoke receipt establishing the required per-arm real-sandbox grade before the remaining cells were released, and no smoke or strict-validation receipts. The outcome tables and operator-reported grading chronology do not replace those records.

No strict-validation output for all Standard records before analysis is present in the public snapshot. Strict release-checklist compliance, including Standard records and smoke/strict-validation receipts, is not established for this round. It is published as a descriptive exception; no placeholder records or validation receipts are supplied here.
