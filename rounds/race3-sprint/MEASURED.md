# Measured evidence

This descriptive round compares five language implementations across three sprint waves on one MacBook and one Mac Studio. `records.jsonl` contains 267 Standard 1.2 measurement records projected from the public curve table: one record per scored arm, host, wave and checkpoint, including all 30 FINALs. The underlying score and search tables, per-case status/step-metric projections, repeat coverage, timing, audit, CPU/load and snapshot-copy summaries remain in `results/`.

These checkpoint records are not independent repetitions. The bundle does not include implementation source, complete FINAL repeat files, a clean-copy FINAL regrade, or complete token totals. Unsupported Standard fields carry declared m-codes. See [`MISSING.md`](MISSING.md) and the round README for the gaps, deviations and limits.
