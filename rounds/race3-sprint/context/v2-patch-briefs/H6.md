Also make kitsum.sh honour `RACE3_KIT_DIR` when it is set (default unchanged).
Run `python3 -m py_compile checks.py` and `bash -n kitsum.sh`. Run `bash kitsum.sh` if the sandbox allows it, and print the hash. Final message: the diff summary.
