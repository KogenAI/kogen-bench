# Input provenance

The read-only source was the frozen harness's `inputs/` tree, containing 494 files (493 under spec/conformance plus NCASES). Its registered digest was independently verified as `2eeacf689c103dc3`. The digest method hashes the sorted lines `SHA256  ./relative/path\n` for every input file, then takes the first 16 hexadecimal digits of the SHA-256 of those lines. This includes NCASES. The suite's separately supplied `suite_sha.py` uses a different length-prefixed digest over spec/conformance and is not the registered hash method.

The exported tree has home paths rewritten to `~`, real email patterns redacted if encountered, and one synthetic signing private-key body replaced by a redaction marker at `spec/quint/cli-fixtures/synthetic-key.pem`. Public hostnames are normalized to MacBook/Mac Studio. Its digest **before adding this bundle's checksum manifest** is `3faedda8498534d3`, after correcting six stale relative links to retained public targets. It therefore is a sanitized copy of the raced inputs, not a byte-identical reconstruction. The signing fixture cannot be used as originally supplied. Synthetic `.invalid` fixture email addresses and the two fake bearer strings in protocol documentation are retained; they are not operator credentials. References to the authentication filename in suite/audit code are retained, but no actual account authentication file is included.

`inputs/SHA256SUMS` records the exported bytes. `PROVENANCE.tsv` records each source file's full SHA-256 and exported SHA-256, plus the transformation. Embedded source digests in raced manifests remain historical assertions and are not silently rewritten to describe sanitized bytes. There are no arm source trees or snapshot copies in the public bundle. The spec's models, fixture programs and the conformance runner are benchmark inputs and are included as requested.

The six supplied run directories contain harness copies and output, but no input trees. Their preserved `checks.txt` records all report the raced digest and PASS frozen-inputs. The independently checked supplied frozen tree is the sole input copy used here.
