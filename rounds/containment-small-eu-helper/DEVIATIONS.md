# Deviations and exclusions

This round contains the fresh No sandbox, Bubblewrap setup, and Kogen helper (under qualification) measurements from the same run. It does not reuse earlier No sandbox or Bubblewrap setup numbers. The previous comparison rounds are available as [containment-small-eu-v2](../containment-small-eu-v2/README.md) and [containment-small-eu](../containment-small-eu/README.md).

The nono setup was not selected. No macOS behavior was measured. The helper interruption qualification exercised the No sandbox path rather than interrupting the helper path.

An earlier rehearsal and dry cells on a second machine are excluded from these results. One dry cell ran while a lock on that second machine was breached; it is not part of the measured result. The reported matrix consists only of the three-repetition measurement summarized in this round.

Kogen helper running bash is a separate launch-availability check. Its three LAUNCH-FAILED cells are not containment successes and are not combined with the helper's static-fixture containment observations.

A pre-declared re-measure with the fixed helper build will appear as its own round.
