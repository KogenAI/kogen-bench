The requested timing estimator is labelled “legacy-classifier median build/test seconds per observed write interval.” J1 reuses the historical timing classifier described below, with only Python's language name added. Race 4 supplies implementation and definitions, never timing observations. Every deciding timing observation comes from Race 5's own commands. Successful shell/file writes and native file changes create completion boundaries. In each closed interval between boundaries, take the union of recognized build/test/mixed command time, including zero intervals; exclude the final open interval. Pool intervals across the applicable runs and take one median, rather than a median of run medians. The exact legacy script remains `timing_reused.py`.

This is a proxy for work between observed writes, not an assured measurement per source-code change. Logging and formatting can create boundaries; commands combining edits and tests cannot be separated internally; pooling weights runs by interval count. Failed completed commands are included. Static classification cannot prove every short-circuited subcommand ran, and tests may compile internally. Invocations pair timestamps by event type, item ID and item type within each turn, never across turns. Command intervals are clipped at FINAL; unfinished intervals are censored in totals. Empty timestamp-less retries are excluded and counted. Interrupted work is bounded by its final observed event. Command wall is an interval union; model-wait is observed turn wall minus command union, including reasoning, messages, stalls and file-change tools, not pure model compute. Category summed work can exceed union time where commands overlap.

The legacy classifier omits ordinary `python -m pytest` and `python -m unittest` tests: adding a language label did not add patterns. This is an actual classification omission, not a missing Python build step. `timing_python_expanded.py` adds only those patterns, replaying the same events in memory. Across four Mac Python cells it reclassifies 245 commands; 230 were previously other, totaling 1,781.324 summed command seconds. Python's pooled median changes from 27.063999891281128 to 27.9760000705719. All expanded observations and numerical differences are retained in the final sensitivity data and results JSON.
