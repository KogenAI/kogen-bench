# Results guide

cells.tsv has 26 completed cells: 20 PRIMARY Mac cells, two Go REPAIRED-only make-ups, and four nondeciding Linux robustness cells. Interrupted Studio A has no FINAL and is described in INCIDENTS.md. The original scores of four INVALID cells remain in the explicitly requested as-scored PRIMARY sample. y means no invalidating receipt/published-audit/Kogen gate found in inspected evidence; it never certifies a completed full audit. n means the frozen invalidating gate applies; validity_reason names it.

Tokens are exact cumulative identified-session total_token_usage at or before FINAL. Cached input and reasoning output are subsets, not extra tokens. JSON retains component totals and receipt timestamps; the prose table rounds millions. J1 is the legacy-classifier median union of build/test seconds between successful observed writes, including zero intervals and excluding the last open interval. It is a proxy per write interval; logging/formatting can create boundaries, mixed edits/tests are inseparable and pooled intervals weight runs unequally. Python -m pytest/unittest were missed by the legacy classifier; the expanded sensitivity is disclosed in METHOD.md.

results.json retains aggregate decision inputs, sensitivities, exact token components, per-cell timing summaries and limitations. change-intervals.json contains only numeric write-interval seconds by arm; it permits recomputation of per-cell and pooled J1 medians without commands or case content. source-receipts.json retains 22 Mac/make-up source hashes and per-arm pass/fail/error counts, never case rows or IDs. Linux scores/tokens/timing are retained from the original collector; Linux does not have the separate 22-cell source verification pass. audit-summary.tsv records aggregate gate findings and audit completion; run-clocks.tsv records observed wave clocks.

Run python3 -B results/recompute.py from publish/ to verify public arithmetic and checksums. Official scores and tokens are supplied observations: their independent source derivation, hidden-suite executable regrading, classifier replay and incomplete historical perfect-score search cannot be recomputed from this public bundle. The raw analysis and all transcripts are private.
